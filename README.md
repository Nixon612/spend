# Spend

A private expense tracker for people with more month than money.

Track what you spend, set aside money for emergency, savings, and buffer, and see how much you can safely spend per day for the rest of the month.

## Use it

**https://nixon612.github.io/spend/**

Or install it:
- **Desktop (Chrome/Edge):** click the Install button in the address bar or the banner in the app.
- **Android (Chrome):** tap the Install button in the app, or the ⋮ menu → Install app.
- **iPhone (Safari):** tap Share → Add to Home Screen.

Once installed, it works offline.

## Your data

Everything stays on your device. There is no server, no account, no sync. Expenses and settings live in your browser's local storage. Export to JSON any time from Settings.

If you clear browsing data on your browser, your expenses are gone. Export a backup occasionally.

## Features

- Two-tap entry: type amount, tap category, done
- "Safe to spend per day" — the only number that matters
- Split expenses with others; only your share counts
- Monthly breakdown by category
- Set aside percentages for Emergency, Savings, and Buffer
- Works offline after first load
- Installable as a PWA on desktop and mobile
- No accounts, no ads, no bank linking
